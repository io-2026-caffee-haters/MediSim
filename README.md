# MediSim
## Czym jest aplikacja
Medisim to edukacyjna gra symulacyjna, w której gracz wciela się w rolę lekarza. Głównym zadaniem jest przeprowadzenie wywiadu z pacjentami, przeprowadzenie niezbędnych badań oraz postawienie poprawnej diagnozy w ograniczonym czasie.

## Instalacja i uruchomienie
1. Przejdź pod adres: https://gamejolt.com/games/medisim/1077562.
2. Pobierz archiwum .zip z grą.
3. Rozpakuj pobrany folder w wybrane miejsce na dysku.
4. Uruchom aplikację, klikając dwukrotnie w plik `MediSimIO.exe`.

## Uruchamianie testów
Testy jednostkowe znajdują się w oddzielnym folderze Tests wewnątrz repozytorium. Aby je uruchomić:
1. Upewnij się, że folder `Tests` jest dołączony do głównego katalogu `Assets` w projekcie Unity.
2. Otwórz projekt w silniku Unity.
3. Przejdź do zakładki __Window -> General -> Test Runner__.
4. W oknie _Test Runner_ wybierz zakładkę _EditMode_ lub _PlayMode_ (zależnie od typu testów).
5. Kliknij przycisk Run All, aby wykonać wszystkie dostępne testy.
